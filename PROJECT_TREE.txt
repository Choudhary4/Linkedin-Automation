Anti-Detection Techniques:
==========================

Mandatory (3/3):
✓ 1. Human-like Mouse Movement
     - Bézier curve trajectories
     - Variable speed (slow start/end, fast middle)
     - Micro-corrections and overshoot
     - Natural hovering

✓ 2. Randomized Timing Patterns
     - Random delays (2-5 seconds)
     - Human "thinking time" (1-4 seconds)
     - 10% chance of long pauses

✓ 3. Browser Fingerprint Masking
     - Remove navigator.webdriver
     - Random user agents (6 variations)
     - Plugin property masking
     - Screen property randomization

Additional (7/5 Required):
✓ 4. Random Scrolling Behavior
✓ 5. Realistic Typing Simulation
✓ 6. Mouse Hovering & Movement
✓ 7. Activity Scheduling (9-5 PM)
✓ 8. Rate Limiting & Throttling
✓ 9. Random Break Simulation
✓ 10. Random Viewport Sizes


Database Schema:
================

connection_requests
├── id (INTEGER PRIMARY KEY)
├── profile_url (TEXT UNIQUE)
├── profile_name (TEXT)
├── company (TEXT)
├── message (TEXT)
├── sent_at (DATETIME)
└── status (TEXT: pending/accepted/rejected)

messages
├── id (INTEGER PRIMARY KEY)
├── profile_url (TEXT)
├── profile_name (TEXT)
├── content (TEXT)
└── sent_at (DATETIME)

search_history
├── id (INTEGER PRIMARY KEY)
├── query (TEXT)
├── location (TEXT)
├── result_count (INTEGER)
└── searched_at (DATETIME)


Quick Commands:
===============

Setup:
  ./setup.sh                              # Automated setup
  make build                              # Build application

Search:
  ./subspace -action=search -keywords="Software Engineer"

Connect:
  ./subspace -action=connect -keywords="Product Manager" -max-results=10

Message:
  ./subspace -action=message -message="Thanks for connecting!"

Debug:
  LOG_LEVEL=debug HEADLESS=false ./subspace -action=search
